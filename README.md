# Datos de Investigación - Tesis de Grado

## Descripción del Proyecto
Este repositorio contiene los datos y resultados obtenidos durante el desarrollo de la tesis titulada "DESARROLLO DE UN PROTOTIPO DE RASTREO CON GPS/GSM PARA LA VIGILANCIA DEL GANADO BOVINO", ademas contiene los respectivos anexos utilizados para el mismo.

## Estructura de los Archivos
* `datos_monitoreo_bovino_2026.xlsx`: Datos principales con los registros completos recopilados en el campo de estudio.
* Datasheet de los componentes utilizados

## Tecnologías Utilizadas
* Almacenamiento y procesamiento de datos: Microsoft Excel.
